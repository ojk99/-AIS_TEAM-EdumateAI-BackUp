# [EduMate AI] 2022 개정 교육과정 초등국어 단원 목차 및 핵심 학습요소 데이터
# 영역 구분: 듣기·말하기, 읽기, 쓰기, 문법(언어), 문학, 매체

================================================================================
[1~2학년군] 초등학교 1~2학년 국어 교육과정
================================================================================

[1학년 1학기]
- 1단원: 바른 자세로 읽고 쓰기
  * 영역: 읽기 / 쓰기
  * 학습목표: 낱말과 문장을 바른 자세로 읽고 쓴다.
  * 핵심키워드: 연필 쥐는 법, 낱자 쓰기, 글자 모양, 바른 자세, 낱말 소리 내어 읽기

- 2단원: 재미있는 낱말 놀이
  * 영역: 문법(언어)
  * 학습목표: 한글 자음자와 모음자의 이름과 소릿값을 알고 결합한다.
  * 핵심키워드: 자음자, 모음자, 글자 만들기, 소릿값, 닿소리, 홀소리, 낱말 잇기

- 3단원: 글자를 만들어요
  * 영역: 문법(언어) / 읽기
  * 학습목표: 자음자와 모음자를 합쳐 글자를 만들고 소리 내어 읽는다.
  * 핵심키워드: 받침 없는 글자, 자모 결합, 글자 읽기, 글자 쓰기

- 4단원: 기분을 말해요
  * 영역: 듣기·말하기
  * 학습목표: 인물의 기분이나 마음을 짐작하고 알맞은 표정과 말로 표현한다.
  * 핵심키워드: 마음 표현, 기분 짐작, 표정과 몸짓, 칭찬하는 말, 고운 말

- 5단원: 생각을 전해요
  * 영역: 쓰기 / 문학
  * 학습목표: 겪은 일이나 상상한 것을 짧은 문장과 그림으로 나타낸다.
  * 핵심키워드: 문장 만들기, 겪은 일 표현, 그림일기 기초, 생각 나누기

[1학년 2학기]
- 1단원: 다정하게 인사해요
  * 영역: 듣기·말하기
  * 학습목표: 상황에 맞는 인사말을 바른 태도로 나눈다.
  * 핵심키워드: 때와 장소, 인사말, 대화 예절, 듣는 태도

- 2단원: 띄어 읽어요
  * 영역: 읽기 / 문법
  * 학습목표: 문장 부호(마침표, 물음표, 느낌표, 쉼표)를 알고 알맞게 띄어 읽는다.
  * 핵심키워드: 띄어 읽기, 문장 부호, 마침표(.), 물음표(?), 느낌표(!), 쉼표(,), 숨 쉬는 곳

- 3단원: 받침이 있는 글자
  * 영역: 문법(언어) / 쓰기
  * 학습목표: 받침이 있는 낱말을 바르게 읽고 정확하게 쓴다.
  * 핵심키워드: 받침 글자, 대표 받침(ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅇ), 쌍받침 기초, 낱말 쓰기

- 4단원: 고운 말을 써요
  * 영역: 듣기·말하기 / 문법
  * 학습목표: 상대방을 배려하며 바르고 고운 말을 사용한다.
  * 핵심키워드: 배려하는 말, 고운 말, 바른 말, 상처 주는 말 삼가기

- 5단원: 겪은 일을 글로 써요
  * 영역: 쓰기
  * 학습목표: 하루 동안 있었던 인상 깊은 일을 차례대로 문장으로 쓴다.
  * 핵심키워드: 일기 쓰기, 일어난 순서, 생각과 느낌, 문장 연결

[2학년 1학기]
- 1단원: 생각을 나타내요
  * 영역: 쓰기 / 읽기
  * 학습목표: 시나 노래를 감상하고 자신의 생각이나 느낌을 표현한다.
  * 핵심키워드: 동시, 말의 재미, 반복되는 말, 느낌 표현, 흉내 내는 말(의성어, 의태어)

- 2단원: 자신 있게 말해요
  * 영역: 듣기·말하기
  * 학습목표: 여러 사람 앞에서 알맞은 목소리 크기와 자세로 발표한다.
  * 핵심키워드: 자신감 있는 태도, 알맞은 목소리, 청중 바라보기, 바른 자세

- 3단원: 마음을 짐작해요
  * 영역: 문학 / 읽기
  * 학습목표: 이야기 속 인물의 말과 행동을 통해 마음을 짐작한다.
  * 핵심키워드: 인물의 마음, 표정과 행동, 말의 뉘앙스, 까닭 찾기

- 4단원: 말놀이를 해요
  * 영역: 문법(언어)
  * 학습목표: 소리와 모양을 흉내 내는 말을 알고 문장에 알맞게 쓴다.
  * 핵심키워드: 의성어, 의태어, 흉내 내는 낱말, 말놀이, 생생한 표현

- 5단원: 낱말의 뜻을 짐작해요
  * 영역: 읽기 / 문법
  * 학습목표: 글을 읽으며 앞뒤 문맥을 살펴 낯선 낱말의 뜻을 짐작한다.
  * 핵심키워드: 문맥적 의미, 낱말 뜻 짐작, 앞뒤 내용 살피기, 낱말 사전 찾기 기초

[2학년 2학기]
- 1단원: 인상 깊었던 일
  * 영역: 쓰기
  * 학습목표: 가장 기억에 남는 일을 떠올려 생각이나 느낌이 드러나게 글을 쓴다.
  * 핵심키워드: 인상 깊은 경험, 일기, 겪은 일의 차례, 생각과 느낌 구체화

- 2단원: 자세하게 소개해요
  * 영역: 듣기·말하기 / 쓰기
  * 학습목표: 주변의 인물이나 사물의 특징을 관찰하여 알기 쉽게 소개한다.
  * 핵심키워드: 설명하기, 특징 파악, 소개하는 말, 듣는 사람 고려

- 3단원: 바르게 띄어 써요
  * 영역: 문법(언어) / 쓰기
  * 학습목표: 낱말과 낱말 사이를 알맞게 띄어 쓰고, 문장 부호를 바르게 쓴다.
  * 핵심키워드: 띄어쓰기, 문장 부호 쓰임새, 큰따옴표, 작은따옴표 기초, 바른 문장

- 4단원: 칭찬하고 배려해요
  * 영역: 듣기·말하기
  * 학습목표: 친구의 장점을 찾아 칭찬하고 대화 예절을 실천한다.
  * 핵심키워드: 칭찬하는 말, 대화 예절, 배려의 언어, 경청

- 5단원: 이야기를 즐겨요
  * 영역: 문학
  * 학습목표: 옛이야기나 그림책을 읽고 인물의 행동에 대해 자신의 생각을 말한다.
  * 핵심키워드: 옛이야기, 인물의 행동 평가, 이어질 이야기 상상, 독서 감상

[3~4학년군] 초등학교 3~4학년 국어 교육과정

[3학년 1학기]
- 1단원: 재미가 톡톡톡
  * 영역: 문학
  * 학습목표: 시나 이야기의 감각적 표현을 찾고 그 재미를 느낀다.
  * 핵심키워드: 감각적 표현, 시각/청각/촉각/미각/후각 표현, 비유적 감각

- 2단원: 문단의 짜임
  * 영역: 읽기 / 쓰기
  * 학습목표: 중심 문장과 뒷받침 문장을 구별하고 하나의 완성된 문단을 쓴다.
  * 핵심키워드: 문단, 중심 문장, 뒷받침 문장, 문단 나누기, 글의 구조

- 3단원: 알맞은 높임 표현
  * 영역: 문법(언어)
  * 학습목표: 대화 상대에 따라 알맞은 높임 표현을 사용한다.
  * 핵심키워드: 높임법, 주체 높임(-시-), 상대 높임(습니다/어요), 높임 어휘(진지, 댁, 연세)

- 4단원: 내 생각은 어때?
  * 영역: 듣기·말하기 / 쓰기
  * 학습목표: 자신의 생각이나 의견과 그 까닭을 조리 있게 밝힌다.
  * 핵심키워드: 의견 제시, 까닭(이유), 주장하기, 논리적 말하기

- 5단원: 내용을 간추려요
  * 영역: 읽기
  * 학습목표: 설명하는 글을 읽고 문단별 중심 내용을 파악하여 글 전체를 요약한다.
  * 핵심키워드: 내용 요약, 중심 내용 간추리기, 설명하는 글, 문단 요약

[3학년 2학기]
- 1단원: 작품을 보고 느낌을 나누어요
  * 영역: 문학
  * 학습목표: 인물의 처지와 마음에 공감하며 작품을 읽고 감상을 나눈다.
  * 핵심키워드: 공감적 읽기, 인물의 처지, 독서 감상, 생각 나누기

- 2단원: 중심 생각을 찾아요
  * 영역: 읽기
  * 학습목표: 글쓴이의 중심 생각(주제)을 문단과 제목을 통해 파악한다.
  * 핵심키워드: 중심 생각, 주제 찾기, 글의 제목과 내용 연관성

- 3단원: 낱말의 관계를 알아요
  * 영역: 문법(언어)
  * 학습목표: 비슷한 말(유의어), 반대말(반의어), 포함하는 말(상하위어)의 관계를 안다.
  * 핵심키워드: 유의어, 반의어, 상위어, 하위어, 낱말 그물, 어휘력 확장

- 4단원: 마음을 담아 편지를 써요
  * 영역: 쓰기
  * 학습목표: 편지의 형식(받는 사람, 첫인사, 전하고 싶은 말, 끝인사, 쓴 날짜, 쓴 사람)을 알고 쓴다.
  * 핵심키워드: 편지 글, 편지의 형식, 전하는 마음, 감사와 사과

- 5단원: 원인과 결과를 생각해요
  * 영역: 듣기·말하기 / 읽기
  * 학습목표: 일어난 일의 원인과 결과를 찾아 인과관계에 맞게 말하고 쓴다.
  * 핵심키워드: 원인과 결과, 인과관계, 그래서, 왜냐하면, 사건의 흐름

[4학년 1학기]
- 1단원: 생각과 느낌을 나누어요
  * 영역: 문학
  * 학습목표: 인물의 성격과 사건의 전개를 파악하며 이야기를 읽는다.
  * 핵심키워드: 인물의 성격, 사건 전개, 배경, 이야기의 구조(발단-전개-결말 기초)

- 2단원: 내용을 짐작해요
  * 영역: 읽기
  * 학습목표: 글의 제목, 사진, 그림, 앞뒤 내용을 바탕으로 이어질 내용을 예측한다.
  * 핵심키워드: 내용 짐작(추론), 단서 활용, 예측하며 읽기

- 3단원: 느낌을 살려 말해요
  * 영역: 듣기·말하기
  * 학습목표: 상황에 어울리는 표정, 몸짓, 말투를 사용하여 실감 나게 말한다.
  * 핵심키워드: 비언어적 표현(표정, 몸짓), 반언어적 표현(말투, 어조, 성량), 실감 나는 발표

- 4단원: 사실과 의견을 구별해요
  * 영역: 읽기 / 쓰기
  * 학습목표: 글에 담긴 내용이 객관적 '사실'인지 글쓴이의 주관적 '의견'인지 구분한다.
  * 핵심키워드: 사실과 의견, 객관적 사실, 주관적 생각, 비판적 읽기 기초

- 5단원: 국어사전과 친해져요
  * 영역: 문법(언어)
  * 학습목표: 국어사전의 자모 순서를 알고 기본형을 찾아 낱말의 뜻을 익힌다.
  * 핵심키워드: 국어사전 찾는 법, 자모 순서, 기본형(어간+다), 사전 낱말 배열

[4학년 2학기]
- 1단원: 이어질 장면을 생각해요
  * 영역: 문학
  * 학습목표: 이야기의 흐름을 파악하고 뒷이야기를 상상하여 창의적으로 표현한다.
  * 핵심키워드: 뒷이야기 상상, 사건의 인과, 창의적 글쓰기

- 2단원: 의견이 드러나는 글을 써요
  * 영역: 쓰기
  * 학습목표: 문제 상황을 파악하고 해결 방안과 알맞은 까닭을 제시하는 제안하는 글을 쓴다.
  * 핵심키워드: 제안하는 글, 문제 상황, 해결 방안, 타당한 까닭

- 3단원: 문장의 짜임을 알아요
  * 영역: 문법(언어)
  * 학습목표: '누가/무엇이'와 '어떠하다/어찌하다/무엇이다'의 문장 성분 구조를 안다.
  * 핵심키워드: 문장 성분 기초, 주어적 요소, 서술어적 요소, 문장 완성하기

- 4단원: 회의를 해요
  * 영역: 듣기·말하기
  * 학습목표: 회의의 절차와 규칙을 알고 다른 사람의 의견을 경청하며 회의에 참여한다.
  * 핵심키워드: 학급 회의, 회의 절차, 발언권, 제안과 찬반, 다수결과 소수 의견 존중

- 5단원: 생각을 나누는 글을 읽어요
  * 영역: 읽기 / 매체
  * 학습목표: 전기문이나 안내문을 읽고 인물의 삶이나 유용한 정보를 파악한다.
  * 핵심키워드: 전기문, 인물의 삶, 시대적 배경, 본받을 점, 매체 정보 읽기

[5~6학년군] 초등학교 5~6학년 국어 교육과정

[5학년 1학기]
- 1단원: 대화와 공감
  * 영역: 듣기·말하기
  * 학습목표: 상대방의 처지를 이해하고 공감하며 대화하는 태도를 기른다.
  * 핵심키워드: 공감적 대화, 경청, 맞장구치기, 마음을 나누는 대화, 언어폭력 예방

- 2단원: 작품을 감상해요
  * 영역: 문학
  * 학습목표: 시와 소설에 쓰인 비유적 표현(직유법, 은유법)의 효과를 파악한다.
  * 핵심키워드: 비유적 표현, 직유법(~처럼, ~듯이), 은유법(A는 B이다), 참신한 표현

- 3단원: 글의 구조를 살펴요
